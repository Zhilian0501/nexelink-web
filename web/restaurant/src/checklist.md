# 店家上線檢查清單

這份清單照實際安裝順序排列，到店裡一項一項打勾。全部完成大約需要 2～3 小時，建議挑非營業時間到店。勾選會保存在這台手機上，換頁回來不會不見。

## 出發前準備

**先跟老闆要的資料**

- [ ] 老闆自己的 Email（要能收信，用來註冊與找回密碼）
- [ ] 店名、電話、地址、統一編號（有的話）、營業時間
- [ ] 店家 Logo 圖檔（沒有也可以，會先用 NEXELINK Logo）
- [ ] 菜單：品名、售價、分類、加點選項（辣度、冰量等），最好先填進 Excel 範本
- [ ] 商品照片（選填，可以之後再補）
- [ ] 有外國客人的店：菜單的英文名稱
- [ ] 桌位清單：桌號與座位數
- [ ] 營運方式：先付款還是用餐後付款、要不要收服務費、自動或人工接單、有沒有外帶與候位
- [ ] 員工名單，哪些人是店長

**要帶去或請店家準備的東西**

- [ ] 開通碼（在平台後台產生，確認方案是對的）
- [ ] 平板：服務生端、廚房端各一台，有候位的加一台叫號螢幕
- [ ] 平板支架與充電線（廚房的要放在不會被水濺到的地方）
- [ ] 出單機（選配）：確認紙寬 58 mm 或 80 mm，以及平板能不能連上列印
- [ ] 桌卡或壓克力立牌（可以先從系統印紙本桌卡，之後再代印）

**店裡的網路**

- [ ] Wi-Fi 名稱與密碼
- [ ] 在廚房、櫃台、最遠的桌位各測一次訊號，用手機打開網頁不卡
- [ ] 客人用自己的 4G/5G 也能點餐，不一定要給客人 Wi-Fi

## 帳號開通與基本設定

用老闆的手機或電腦操作，讓老闆自己設密碼。每一步都可以按「回上一步」修改。

- [ ] 打開點餐系統網址 →「我是老闆」→ 註冊
- [ ] 收 Email 驗證碼並輸入
- [ ] 填店家資料（店名、電話、地址、Logo、營業時間）
- [ ] 選店型（飲料店／小吃／餐廳／咖啡廳），系統會套用建議設定
- [ ] 輸入開通碼
- [ ] 讀完並勾選同意服務條款與隱私權政策
- [ ] 設定 → **功能管理**：只開這家店用得到的（內用、外帶、候位、呼叫服務生、廚房 KDS、中英雙語菜單）
- [ ] 設定 → **營運流程**：付款時機、接單方式、服務費 %、「需要開桌後才能點餐」、出單機紙寬
- [ ] 設定 → **管理密碼**：4～6 位數字，只給老闆與值班主管知道
- [ ] 設定 → **外觀**：主色、菜單呈現方式、歡迎詞
- [ ] **員工**：新增每位員工與密碼，設定店長；決定要不要開「服務生端要先登入」和店員的折扣上限

## 菜單、桌位與 QR Code

**菜單**

- [ ] 先建選項群組（例如辣度、冰量、甜度、加點），設定必選或選填、加價
- [ ] 菜單 → Excel 匯入：下載範本、填好、上傳，先看預覽再確認（或一項一項新增）
- [ ] 和老闆一起核對每一項的價格與加點
- [ ] 用「調整順序」拖曳排好分類與商品順序
- [ ] 開了雙語菜單：確認「還有 N 項沒有英文名稱」的提示已經消失
- [ ] 用自己的手機打開客人點餐頁，從頭看一遍菜單

**桌位與 QR Code**

- [ ] 桌位與 QR Code → 新增桌位（可以批次新增，例如 A1～A10），填座位數
- [ ] 選桌卡樣式後列印桌卡（或從同一頁下單壓克力代印）
- [ ] **每張桌卡都用手機掃一次**，確認畫面上的桌號和實際桌子一樣，再貼上去
- [ ] 有外帶：列印外帶點餐立牌，放在櫃台
- [ ] 有候位：候位 → 列印候位立牌，放在門口；用不同品牌的手機掃描試取一個號
- [ ] 桌卡遺失或被拍走時：桌位頁按「重新產生 QR Code」，舊的桌卡就會失效

## 裝置配對與平板設定

每台平板只要配對一次，之後打開就是對應的畫面。裝置數量有方案上限。

**配對**

- [ ] 老闆端 → 裝置 → 填名稱（例如「櫃檯 iPad」「廚房平板」）、選用途 → 產生配對碼
- [ ] 在平板打開點餐系統網址 →「我要新增裝置」→ 輸入 6 位數配對碼（或直接掃配對 QR Code）。配對碼 10 分鐘內有效
- [ ] 服務生端、廚房端、叫號螢幕各配對一台
- [ ] 在裝置頁確認每台都顯示「連線中」

**平板本身的設定**

- [ ] 用瀏覽器的「加到主畫面」，之後從桌面圖示打開
- [ ] 關掉自動鎖定：iPad 是「設定 → 螢幕顯示與亮度 → 自動鎖定 → 永不」；Android 是「螢幕逾時」調到最長
- [ ] 音量調大，關掉靜音與「勿擾」
- [ ] 每次開啟後按一下「點一下開始」，提示音才會響、螢幕才會保持常亮
- [ ] 插上充電線，放上支架

**出單機（有的話）**

- [ ] 先讓平板能列印到出單機（iPad 用 AirPrint，Android 依出單機廠商的列印服務）
- [ ] 設定 → 營運流程 → 出單機紙寬選 58 或 80 mm
- [ ] 從服務生端印一張廚房單、一張收據，確認字沒有被切掉

## 上線前完整試跑一輪

請老闆或員工當客人，用自己的手機走完下面每一步。全部正常才算可以上線。

1. 掃桌上 QR Code，選一道有加點的菜，寫備註，送出。
2. 服務生端響鈴，按「接單」（自動接單的店會直接進廚房）。
3. 廚房端看得到單和備註，按「開始」、「完成」。
4. 服務生端按「已送達」；客人手機上「我的訂單」狀態跟著變。
5. 客人再加點一次；再按「呼叫服務生」，服務生端有響鈴。
6. 開了雙語：客人點餐頁右上角切換 EN，確認菜名變英文。
7. 結帳：打一個 9 折（店員登入時應該要店長核准），用「平均分攤」分兩次收，印收據。
8. 開另一桌點餐，試「換桌」到空桌，再試「併桌」。
9. 收款紀錄 → 作廢一筆（需要店長或管理密碼），再重新結帳。
10. 外帶：掃外帶立牌點一筆，在櫃台收款。
11. 候位：掃候位立牌取號，叫號螢幕叫號、重新叫號，客人手機有提醒。
12. 在服務生端按「暫停接單」，客人頁面顯示暫停；再按「恢復接單」。
13. 拔掉 Wi-Fi 幾秒，平板上方出現紅色斷線提示；恢復後自動補上訂單。
14. 日結：看營業額、收款方式、收款人員是否正確。

- [ ] 以上 14 步全部正常
- [ ] 試跑的訂單都已結帳或取消，桌子都回到「空桌」（試跑金額會算進當天營業額，請老闆知道）

## 員工教學與交接

**教學（每個角色 10～15 分鐘）**

- [ ] 老闆：今日總覽、菜單與售完、日結與報表、員工與操作紀錄、暫停接單
- [ ] 店長：核准折扣、取消、作廢；換桌併桌；日結對帳
- [ ] 服務生：員工登入與換班、開桌、接單、代客點餐、呼叫、結帳與分開付款、清桌
- [ ] 廚房：開始與完成、按品項打勾、復原（5 分鐘內）、售完、暫停接單
- [ ] 把「[老闆操作說明](guide.html)」的連結傳給老闆

**交接給老闆的東西**

- [ ] 老闆自己設的登入密碼與管理密碼（我們不要留存）
- [ ] 點餐系統網址、外帶點餐網址
- [ ] NEXELINK 客服聯絡方式
- [ ] 方案與到期日（月費／年費方案），到期前 14 天系統會提醒

**上線後追蹤**

- [ ] 第一個營業日：尖峰時段到場或電話待命
- [ ] 第 3 天：在平台後台「營運看板」確認這家店有同步、有訂單
- [ ] 第 7 天：回訪老闆，記下問題與建議，回報給開發
- [ ] 桌卡改成壓克力版：老闆可以從「桌位與 QR Code → 壓克力代印」下單
