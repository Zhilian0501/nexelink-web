老闆操作說明

NEXELINK 點餐系統不用安裝 App，用瀏覽器打開就能用。這份說明照一天的營業順序排列，遇到問題可以直接跳到最後的「常見問題」。

系統的組成

一家店由五個畫面組成，各自在不同的裝置上。

畫面 誰在用 在哪裡打開 用來做什麼
老闆端 老闆 手機或電腦，用 Email 登入 菜單、桌位、員工、報表、設定
服務生端 櫃檯、外場 配對過的平板 接單、桌位、結帳、候位、售完
廚房端（KDS） 廚房 配對過的平板 看單、按開始／完成
叫號螢幕 門口候位區 配對過的平板或電視 顯示叫號與取號 QR Code
客人點餐頁 客人 客人自己的手機掃桌上 QR Code 點餐、加點、看進度、呼叫服務生

老闆端左下角有「切換到服務生端」「切換到廚房端」，老闆自己也能幫忙接單。平板不用帳號密碼，是用「配對碼」登入的，老闆可以隨時在「裝置」解除。

第一次設定

老闆端「今日總覽」最上方有開店任務清單，照順序做完，進度條滿了就可以開始營業。

  1. 建菜單：菜單 → 先建「選項群組」（辣度、冰量、加點），再建分類和商品。商品多的話用「Excel 匯入」，下載範本填好上傳即可。
  2. 設桌位：桌位與 QR Code → 新增桌位（可批次新增 A1～A10），填座位數。
  3. 印桌卡：同一頁選樣式後列印，或下單壓克力代印。貼上前每張都用手機掃一次確認桌號。
  4. 配對平板：裝置 → 產生配對碼 → 平板打開網址按「我要新增裝置」輸入。
  5. 設管理密碼：設定 → 管理密碼。取消已接單的訂單、作廢收款、大額折扣都要用到。
  6. 試點一筆：用自己的手機掃桌卡點一筆，從接單走到結帳。

另外建議設定的地方

  • 設定 → 功能管理：用開關決定要不要用內用、外帶、候位、呼叫服務生、廚房 KDS、中英雙語菜單。關掉的功能會從畫面上隱藏，資料保留。
  • 設定 → 營運流程：付款時機（先付或餐後付）、自動或人工接單、服務費 %、「需要店員開桌後客人才能點餐」、備註字數、出單機紙寬。
  • 設定 → 外觀：客人點餐頁的主色、列表或大圖卡、歡迎詞（例如「今日推薦：番茄牛肉麵」）。
  • 員工：新增員工與各自的密碼，指定店長。店長可以核准折扣、取消、作廢，不用把管理密碼告訴每個人。

每天開店

開店前花 2 分鐘做這幾件事，營業中就不會漏單。

平板系統更新、重開機或瀏覽器被關掉後，都要再按一次「點一下開始」。

營業中

一筆訂單的流程

  1. 客人掃桌上 QR Code 點餐、送出。按「＋」會先跳出商品畫面，可以選加點、寫備註。
  2. 服務生端響鈴，訂單出現在「待確認」，按「接單」或「拒單」。設成自動接單的店，會直接進廚房。
  3. 廚房端按「開始」，做好按「完成」。一筆有很多品項時，可以點品項逐項打勾。
  4. 服務生端按「已送達」。客人手機上的「我的訂單」會跟著更新狀態。

按錯了？5 分鐘內可以按畫面下方的「復原」。等太久的單會變紅色提醒。

常用操作

想做的事 怎麼做
開桌 服務生端 → 桌位 → 點空桌 → 選人數 → 開桌
客人加點 客人再掃一次 QR Code 就能加點；不開放加點的店由服務生代點
幫客人點餐 桌位 → 點桌子 →「代客點餐」；外帶按右上角「外帶點餐」
某道菜賣完 服務生端或廚房端 → 售完 → 打開開關，客人就點不到；只影響今天
客人按「呼叫服務生」 服務生端上方出現桌號與需求並響鈴，處理完按「完成」
店裡太忙，先不接新單 服務生端、廚房端或老闆端按「暫停接單」；已送出的單照常製作，服務生代點不受影響
取消一筆已接單的訂單 訂單卡片按「取消」，需要店長或管理密碼
印廚房單 訂單卡片上的印表機圖示
客人用完餐離開 結帳後桌子變「待清潔」，清完按「標記已清潔」

桌位卡片上的「2 位 · 已用餐 15 分鐘」是這桌的人數和已經坐了多久。

候位叫號

  1. 客人掃門口的候位立牌，選人數、填手機（可不填），取得號碼。
  2. 服務生端 → 候位，有空桌時按「叫號」；叫號螢幕與客人手機都會提醒。
  3. 客人到了按「入座」；沒來可以「重新叫號」，或標記「過號」。

結帳

服務生端 → 桌位 → 點桌子 →「結帳」。外帶單在訂單卡片上按「收款」。

一般結帳

  1. 確認左邊的品項與「應收」金額。
  2. 選「現金」或「現場刷卡」。現金可以點快速金額（例如 NT$ 500），系統會算好找零。
  3. 有開發票的店可以填發票號碼。按「確認收款」，可以接著印收據。
情況 怎麼做
打折、招待 按「折扣」，選打折（95 折、9 折、8 折、全部招待）或折抵金額，選原因。超過店員上限時，需要店長或管理密碼
幾個人各付各的 「付款方式」選平均分攤（選幾位）、自訂金額，或依訂單（勾選要付的單）；收完一位會自動算下一位
客人要換位子 桌位 → 點桌子 →「換桌／併桌」→ 選空桌；訂單、帳單與廚房單桌號都會跟著改
兩桌要一起結帳 同上，選一張用餐中的桌子，兩桌帳單合在一起
收錯了 收款紀錄 → 那筆「作廢」→ 選原因，需要店長或管理密碼；這桌會回到未付清，重新結帳即可
補印收據 收款紀錄 → 那筆「列印」

分開付款時，要等整桌付清才算進營業額。作廢其中一筆不會影響其他已收的部分，也不會重複收。

「服務費」由設定 → 營運流程決定，只有內用會收。

打烊與日結

日結單上的營業額只算已付款的訂單，已經扣掉折扣。系統每天凌晨 4 點自動備份，不用另外做。

管理

以下都在老闆端左側選單。

選單 可以做什麼
今日總覽 今天營業額與訂單數、進行中訂單、桌況、待辦提醒（例如平板斷線太久）
訂單 查所有訂單，點進去看明細與這筆的操作紀錄
菜單 新增、修改商品與選項；拖曳排序；售完與上下架；Excel 匯入；開了雙語時填英文名稱
桌位與 QR Code 新增桌位、重新產生 QR Code、列印桌卡、壓克力代印、外帶與候位立牌
候位 候位 QR Code、叫號螢幕、候位設定（有開候位才會出現）
報表 月、季、年營收、成本與利潤、熱銷商品、日結；可匯出 Excel
費用 記錄房租、人事、食材進貨等支出，報表會算進淨利
裝置 配對新平板、修改名稱與用途、解除授權（平板遺失時馬上解除）
員工 新增員工、換密碼、設店長、設為離職；「服務生端要先登入」與店員折扣上限
設定 店家資料（含聯絡人姓名）、功能管理、營運流程、外觀、管理密碼、方案、帳號、更新內容

操作紀錄：員工頁右上角「看操作紀錄」。可以依員工、類型、日期篩選；「需留意」只看作廢、取消、折扣、拒單，並顯示是誰核准的。

方案與續約：設定 → 方案可以看到期日。月費或年費方案到期前，NEXELINK 會寄信說明續約與匯款方式；確認收款後，系統下次同步（每天凌晨，或在方案頁按「立即同步」）就會自動延長，不用輸入開通碼。到期後有 7 天寬限期，期間照常使用；之後客人點餐與平板會暫停，老闆仍可登入查看、匯出資料。

更新內容：每次重大更新後，第一次進入系統會跳出這一版的介紹，按「知道了」就不會再出現。設定 → 更新內容可以重看所有版本。

常見問題

問題 怎麼處理
新單沒有聲音 按一下畫面上的「點一下開始」；確認平板沒有靜音或「勿擾」；廚房端右上角「提示音」是開的
畫面上方出現紅色「連線中斷」 店裡網路斷了。先用口頭確認新單，網路恢復後會自動補上；客人送單與結帳會自動重試，不會重複
平板變成配對畫面 可能被解除授權或瀏覽器資料被清除。老闆端 → 裝置重新產生配對碼再配一次
平板要輸入員工密碼才能操作 開了「服務生端要先登入」。員工輸入自己的密碼；忘記的話老闆到「員工」幫他換一組
忘記管理密碼 老闆登入 → 設定 → 管理密碼，輸入登入密碼後設一組新的
忘記老闆登入密碼 登入頁按「忘記密碼」，用 Email 重設
客人說掃了沒反應或顯示錯誤 用自己手機掃同一張桌卡試試；桌卡若重新產生過 QR Code，舊桌卡會失效，要換新的
客人點餐頁顯示「這桌還沒開桌」 開了「需要開桌後才能點餐」。服務生端 → 桌位 → 開桌
客人點餐頁顯示「暫停接單」 有人按了「暫停接單」。服務生端或廚房端右上角按「恢復接單」
客人點不到某道菜 可能設了售完或下架。服務生端 → 售完，或老闆端 → 菜單檢查
候位手機號碼輸入錯誤 輸入 09 開頭的 10 碼，+886、橫線、空白系統會自動整理
商品照片不見了 通知 NEXELINK 客服；照片會顯示品名第一個字代替，不影響點餐
畫面提醒「方案將到期」 依 NEXELINK 寄來的續約信完成匯款，確認後系統會自動延長；也可以在設定 → 方案輸入續約開通碼

其他問題請聯絡 NEXELINK 客服，告訴我們店名、發生時間和畫面截圖。
